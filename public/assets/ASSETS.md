# Asset provenance

## `track-carpathians.webp`

- Generated with the built-in OpenAI image-generation tool on 2026-07-31.
- The user-supplied screenshot was used only as composition and mood reference.
- The prompt required an original empty Carpathian-inspired two-lane landscape
  with no copied character, gates, UI, text, or logos.
- Converted locally from generated PNG to WebP with `cwebp -q 84`.

## `runner.webp`

- Generated with the built-in OpenAI image-generation tool on 2026-07-31.
- Prompted as a single original faceless runner on a flat magenta chroma key.
- The background was removed locally with the installed imagegen
  `remove_chroma_key.py` helper.
- Converted locally from alpha PNG to WebP with `cwebp -q 88 -alpha_q 100`.

Neither image contains third-party branding or copied text.
